游览路线

长洲岛／黄埔军校旧址 → 广东省博物馆 → 广州塔

当日行程安排

  1. 07:15–08:00准备

    早餐、出发准备

    带证件，确认省博与军校预约信息。建议按时出发，为下午行程预留缓冲。

  2. 08:00–09:30交通

    酒店到长洲岛

    按乘车预留90分钟，国庆可能更久。轮渡不是建议交通，以免叠加候船不确定性。

  3. 09:30–10:45游览

    黄埔军校旧址重点参观

    以校本部为主，不把纪念碑、墓园、炮台全部走遍。按当日预约及开放区域参观。

  4. 10:45–11:15交通

    转往金洲北路午餐

    如选择人人菜馆，提前结束军校参观，乘车前往金洲北路45号；不要把路程算成用餐时间。

  5. 11:15–12:00用餐

    岛上午餐

    人人菜馆候选：黄埔炒蛋、烧鹅或白切鸡配青菜米饭。先问出餐时间；等位久就换简餐，12点左右离岛。

  6. 12:00–14:00交通

    长洲岛到省博

    留两小时给乘车、拥堵、下车步行与安检。若路况预计赶不上票面时段，及时调整，实际交通时间以当日路况为准。

  7. 14:00–16:15游览

    广东省博物馆

    以预约成功时段为准。广东历史、自然等展览按兴趣选两部分，建议选择重点内容参观所有楼层。

  8. 16:15–17:00交通

    花城广场简要参观、过江

    广场拍照后乘车或轨道交通去广州塔，不安排年长游客步行过海心桥。

  9. 17:00–18:00用餐

    晚餐

    先用餐再看夜景；建议选择就近家常餐厅。

  10. 18:00–19:00游览

    广州塔外观与珠江夜景

    建议地面看塔。登塔是付费可选项目，另按票面时段安排，替换本段并延后返程。

  11. 19:00–20:00收尾

    返回酒店

    晚间不另行安排跨区游览。省博未约到：下午改花城广场短游与酒店休息，不临时加长步行。

游览建议

省博现行16:00停止入场，需要实名分时预约。建议争取14:00附近的可用时段；若预约时间不同，以票面时段倒推离岛时间。岛上以黄埔军校旧址为主要参观点。

餐饮安排

午餐可选择长洲岛人人菜馆，品尝黄埔炒蛋及烧鹅。省博与广州塔片区的具体餐厅尚待核实，晚餐建议就近选择粥粉面或烧味饭。

长洲岛黄埔军校旧址广东省博物馆花城广场广州塔
长洲岛片区背景 · 建议军校外20分钟以内
历史与文化背景
这里说的“岛”是黄埔区长洲岛，黄埔军校旧址所在地。它兼有村落生活与近代军事历史，不能和海珠区黄埔古港混为同一个地点。
主要看点
把江面、岛岸与军校的位置联系起来，理解珠江水道对于广州的交通和防务意义。村落生活只在军校附近顺路观察。
建议游览方式
酒店直接乘车至军校附近 → 参观 → 附近午餐 → 离岛。不排环岛骑行，也不把码头、炮台与村落全串起来。
游览提示
12点左右离岛是为了下午省博；想坐轮渡必须另算候船和码头接驳，不能沿用当前乘车时间表。

黄埔军校旧址重点 · 建议约90分钟
历史与文化背景
黄埔军校于1924年创办，是第一次国共合作背景下的重要军事学校。这里的意义不只是一座校舍，而是近代中国人才培养与政治军事变迁的历史现场。
主要看点
先读办学背景，再看校本部空间与人物资料。比较课堂、办公、生活的安排，想象学员一天如何度过；把历史人物放回当时环境理解。
建议游览方式
校本部门前 → 开放展陈中的创校背景 → 一组人物或学员生活内容 → 返回集合。遗址、修复建筑和展陈复原，以现场说明牌区分。
游览提示
不把孙总理纪念碑、墓园、炮台全加进来。实名预约与开放区域看官方票务；遇台阶选择地面部分，不硬走全线。

广东省博物馆重点／预约优先 · 建议约2小时
历史与文化背景
省博把广东历史、自然与艺术放在一起，能将前两天零散看到的港口、民居和工艺串成整体。它不是只看“镇馆之宝”的打卡馆。
主要看点
家庭推荐二选一组合：广东历史＋自然资源，或广东历史＋自己感兴趣的艺术展。历史展找与广州商贸相呼应的内容，自然展看广东山海环境；实际展出以当天为准。
建议游览方式
先在大厅看导览、确认电梯 → 主展约60分钟 → 第二部分约40分钟 → 留时间洗手间与出馆。两家可短时分组，约定同一出口。
游览提示
按预约时段入馆，现行16:00止入。不要把临展全部叠加；若只剩一小时，就认真看一个主题。

背景／参观资料 ↗

花城广场省博出馆顺路 · 建议10–20分钟
历史与文化背景
这里展示广州当代城市中心的尺度，与前两天的西关街巷形成对照。省博、文化建筑、高楼和珠江方向的视线，共同组成今天的城市景观。
主要看点
从省博周边看一眼广场与建筑群，比较公共建筑的外形；找能远望广州塔的位置拍一张全家照即可。
建议游览方式
出馆后仅走最近的一段开放公共区域，再去交通接驳点。广场纵深很长，不从头走到尾。
游览提示
开阔区域遮阴有限。这里是转场中的短停，不再附加海心沙全程或步行跨海心桥。此卡为线路与观察建议。

位置查询（非历史资料） ↗

广州塔重点／登塔可选 · 建议地面45–60分钟
历史与文化背景
广州塔高600米，是广州当代城市天际线的代表。收腰扭转的外形让它得名“小蛮腰”，和珠江两岸共同构成夜景体验。
主要看点
先在稍有距离的江边看完整轮廓，再走近观察结构。地面看塔的重点是“塔与江岸”；登塔看的是“从高处看城市”，两种体验不同。
建议游览方式
过江后先吃晚餐 → 根据开放通道选一段江边 → 看亮灯后的景色 → 乘车返回酒店。登塔若购买门票，替换这一段并按票面重新计时。
游览提示
灯光时间、观景层开放与天气视野都需当日确认。高空项目完全可不选；地面观赏无需购买登塔票，但需遵守外围管理。

F1 · 岛上午餐候选 · 普通家常粤菜

人人菜馆（金洲店）

黄埔炒蛋 · 深井烧鹅

地址：长洲岛金洲北路45号
建议时段：11:15–12:00；10:45左右结束军校参观并转场
规划预算：55–80元/人

像日常用餐那样点：全桌合点黄埔炒蛋、烧鹅或白切鸡二选一、一道豆腐、两份时蔬，米饭按人数；点菜前先问烧鹅有没有、出餐要多久。菜品份量请按实际人数调整。

风味介绍：黄埔炒蛋看嫩滑蛋片；烧鹅先尝皮肉本身，再按口味蘸酸梅酱。这两样贴合岛上风味，不必为了菜名再专程去深井村。

路线衔接：军校旧址 → 乘车到金洲北路店 → 12点左右离岛去省博。地图为街区代表点、尚未核实精确入口，必须用完整店名与地址导航。

资料说明：大众点评相册核实金洲北路45号及参考人均54元；菜品由携程交叉核对，食评包含2021年记录。可作为家庭家常饭候选，当前客群及出餐时间以现场为准。
